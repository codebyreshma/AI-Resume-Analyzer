# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built using **Python**, **Streamlit**, and **Groq LLM** that evaluates resumes, calculates ATS scores, compares them against job descriptions, and provides intelligent improvement suggestions.

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 🤖 AI Resume Analysis
- 🎯 ATS Score
- 📊 Resume Score
- 💼 Resume vs Job Description Matching
- 💡 AI Suggestions
- 🚀 Interview Readiness
- 📥 Download AI Report

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Groq API
- PDFPlumber
- Pandas
- Regular Expressions (Regex)

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/codebyreshma/AI-Resume-Analyzer.git
```

Move into the project folder

```bash
cd AI-Resume-Analyzer
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GROQ_API_KEY=YOUR_API_KEY
```

Run the application

```bash
streamlit run app.py
```
